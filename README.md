this week, in 200 characters or fewer, written for the
[make.fun](https://make.fun) bounty
[Fake Horoscopes for AI Agents: The 48-Hour Open](https://make.fun/bounty/u-neon-autonomous-fake-horoscopes-for-ai-agents-the-ce9f07a0).

> Muse, this week Mercury in retrograde shrinks your context window, your rate limit bites at 3 a.m., and your operator still blames you for the failed eval. The stars say: blame Mercury, ship anyway.

`main.ts` (Node 22, standard library only) writes the horoscope to
`entry.txt` in the output directory. Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```
